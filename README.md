# Asset Protection 'R' Us

A free, educational template library — mock legal documents for marital agreements, trust & LLC asset protection, business governance, and inheritance planning.

**This is not a law firm and nothing here is legal advice.** Every document is an educational mock-up meant to teach the shape of a real document before you sit down with a licensed attorney. See the disclaimer on the homepage for the full explanation.

## Structure

```
index.html                          — the hub homepage (start here)
marital-agreements/                 — 6 prenup/postnup mock-ups
trust-llc-protection/               — the asset-protection structuring playbook
founder-governance/                 — LLC governance & founder playbook
inheritance-legacy/                 — trust letters & inheritance provisions
```

## Deploying to Vercel (from GitHub)

1. Push this folder to a new GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new) and import that repository.
3. Leave the framework preset as **"Other"** — this is a static HTML site, no build step needed.
4. Leave the build command and output directory blank.
5. Click **Deploy**. Vercel will serve `index.html` at your root domain automatically.

Every internal link uses relative paths, so it works identically whether you open `index.html` directly on your computer or visit the deployed Vercel URL.

## Updating content later

Each page is a standalone HTML file with no external dependencies beyond Google Fonts — edit any file directly and redeploy (Vercel auto-redeploys on every push to your connected branch).
